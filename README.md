# 💬 카카오톡 고객 자동 관리 프로그램

카카오톡을 활용하여 고객 명단에 기반한 맞춤형 안내 메시지를 안전하고 효율적으로 발송/관리하는 자동화 솔루션입니다.

---

## 📌 주요 기능
- **엑셀 기반 고객 명단 연동**: `고객명단_양식.xlsx` 파일을 통해 발송 대상 및 고객 정보 관리
- **안전한 발송 지연(Delay) 기능**: 발송 간격 딜레이 설정을 통해 계정 보호
- **설정 파일 기반 관리**: `config.json`을 통해 메시지 문구, 딜레이 시간 등을 손쉽게 커스텀 가능

---

## 🚀 시작하기

### 1. 설정 파일 준비
1. `config.example.json` 파일을 복사하여 `config.json`으로 이름을 변경합니다.
2. `config.json` 파일을 열어 비밀번호 및 발송 메시지, 엑셀 경로 등을 본인 환경에 맞게 수정합니다.

```json
{
  "app_password": "본인_비밀번호_입력",
  "send_mode": "chat_folder",
  "direct_msg": "전송할 안내 메시지 입력",
  "excel_path": "고객명단_양식.xlsx",
  "delay_min": 2,
  "delay_max": 4
}
```

### 2. 고객 명단 작성
- `고객명단_양식.xlsx` 파일에 안내 메시지를 보낼 고객 정보를 입력합니다.

### 3. 프로그램 실행
- `카카오톡_고객자동관리.exe`를 실행하여 발송 작업을 시작합니다.
